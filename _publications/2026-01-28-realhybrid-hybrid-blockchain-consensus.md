Existing hybrid consensus schemes switch between synchronous and asynchronous protocols at the system level, which is inefficient when the network status of individual nodes fluctuates. Realhybrid performs the switch at the node level: every node selects the consensus protocol that suits its current network condition, with dedicated protocols designed for each case. We also build a network model of Realhybrid to relate its performance to system parameters. Experiments show about 29% lower transaction waiting volume and 17% lower confirmation latency than other hybrid consensus schemes.
